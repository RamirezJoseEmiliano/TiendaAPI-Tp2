# Tienda API - Arquitectura en 3 Capas

Proyecto desarrollado en .NET 9 implementando una arquitectura limpia de tres capas (API, Services, Data).

**Características principales:**
- Patrón Repositorio con almacenamiento en memoria.
- Inyección de dependencias (Scoped y Singleton).
- Uso de DTOs para aislar el modelo de dominio.
- Interfaz interactiva de Swagger habilitada.
